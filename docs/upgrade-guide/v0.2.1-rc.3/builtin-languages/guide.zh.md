# 应用内置语言

[English](guide.md) | 中文

## 变更

应用、桌面壳、插件元数据和 Windows 安装器仅内置英文和中文。日语、西班牙语、法语、德语、俄语和葡萄牙语从内置语言选择器及分发资源中移除。Windows 安装器测试仅覆盖保留的两种语言。

已保存的其他语言偏好仍保留。界面选择浏览器或操作系统请求的可用语言，否则回退到英文。插件提供的语言注册能力仍然可用。

## 迁移

1. 如果原来的语言选择不可用，在语言设置中选择英文或中文。
2. 确认语言选择器列出两个内置选项，界面使用所选语言。
3. 开发者运行 `node apps/desktop/scripts/installer-locales.mjs`，确认安装器包含两种语言。
